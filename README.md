# sunflower-rain

A theme for the Claude desktop and mobile apps: ledger paper with warm orange and gold accents, a slowly turning cross-sun crest, a cut-paper portrait silhouette, curved wheat stalks swaying, and a few orange petals drifting down.

- **Light mode (desktop):** ivory paper, wheat in the lower left, the portrait on the right facing right.
- **Dark mode (desktop):** charcoal paper, a large portrait on the left, wheat in the lower right.
- **Phone (portrait):** just the crest and the portrait, colored for the app's light or dark mode.

Motion stops when the system asks for reduced motion. Terminals and editors draw no theme.

## Install

```
/plugin install sunflower-rain --marketplace tt6247/cc-sunflower-rain-theme
```

Answer `y` to add the marketplace, then pick a scope. The theme applies at the start of each session.
